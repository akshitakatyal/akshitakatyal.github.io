# Akshita Katyal — Personal Portfolio & Blog

A responsive, static HTML/CSS/JavaScript portfolio and blog styled after the supplied design reference and personalized from Akshita Katyal’s resume.

## Run locally
Open `index.html` in a browser. No build step, dependencies, server, or database are required.

## Publish
Upload the **contents** of this directory (not the directory itself) to GoDaddy `public_html`, or deploy to GitHub Pages.

## Features
- Responsive hero and about sections with Akshita’s supplied photograph
- Real project descriptions and links to GitHub repositories
- Skills, education, certifications, achievements and accurate contact details
- Six editable technical journal posts based on the supplied resume; these are website editorial drafts, not claimed previously published articles
- Blog category filters, search, load-more, individual article view, bookmarks stored locally, share-link copying
- Contact form opens the visitor’s email client; it does not transmit or store messages

## Editing content
- Edit static page content and links in `index.html`.
- Edit articles in the `POSTS` array at the top of `script.js`.
- Change styling in `styles.css`.
- Change or replace photos and project illustrations under `assets/`.
- The project illustrations are original conceptual mockups, not screenshots of the repositories.

## Privacy
Resume contact phone and email are published on the contact page as requested. Remove the phone number from `index.html` if you prefer not to expose it publicly.

## Visual refresh (professional theme)
- Warm ivory and subtle sage section backgrounds, charcoal typography, forest-green accents.
- Modern Manrope headings and DM Sans body text. Fonts are loaded from Google Fonts when available, with system font fallbacks for offline use.
- Project and blog content, profile photo, links, responsive layout, and functionality are unchanged.
